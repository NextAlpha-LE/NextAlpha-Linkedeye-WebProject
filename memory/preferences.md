# Preferences

## Communication Style
- Direct and action-oriented — uses short imperative sentences ("make deep analyze", "update u memory")
- Prefers doing over discussing — wants results, not proposals
- Comfortable with informal language; no need for formality
- Wants comprehensive work — "deep analyze" signals thoroughness is valued over speed

## Code Style
- **Language:** Python (Django), JavaScript (jQuery), HTML/CSS
- **Naming:** snake_case for Python, `*Model` suffix for Django models, kebab-case URL paths
- **Views:** Function-based views (not class-based)
- **Architecture:** Modular Django apps, custom `LinkedEye*` library packages under `lib/`
- **Frontend:** jQuery + Bootstrap + vendor libs (AnyChart, DataTables, Gridstack)
- **Config:** Environment variables with fallback defaults in settings.py

## Workflow
- Windows 11 + Git Bash (Unix-style commands)
- Docker + Kubernetes deployment pipeline (dev → UAT → prod)
- GitLab registry for container images
- GitHub for source (`le-finspot/linkedeyewebproject`)
- Wants persistent memory across sessions — built a custom memory system for continuity
- Values automation — set up hooks to enforce memory updates
